\section*{Remarks}

\begingroup%
\setlength\parskip{1em}%
This document is not intended to reflect a finish product; rather an archive of
the source at the point of submission for the B. Eng. (L6) dissertation. Given
that not all functional requirements were met in the timeline, some code is
annotated with \texttt{TODO} markers, and Doxygen documentation is occasionally
incomplete.

From the front-matter onwards, the page margins shrink from $2$cm to $0.5$cm to
accommodate the 110-column source listings\footnotemark. As some printers may
not be able to handle such large text areas, printing a couple of test pages
prior to printing the entire document is recommended! Page numbering is also
omitted for the remainder of the document for similar typographical reasons.
%
\footnotetext{The software was initially developed with 120-column files. The
sources have been automatically reset to 110 columns using the
\href{https://clang.llvm.org/docs/ClangFormat.html}{\texttt{clang-format}}
utility, configured by the \texttt{.clang-format} directive file provided
herein. This process may have caused very occasional quirks in formatting. The
original sources can be found via version control on the \texttt{master}
branch.}

The \emph{File Index} structure below corresponds to the directory hierarchy of
the \emph{Optifol} code base: the ``core'' files are detained in
\texttt{Source}, and support files can be found in \texttt{Resources}. Please
note the following exclusions:
\begin{itemize}
    \item A small number of resources are binary files that are not practical to
        display in this document.
    \item Some generated sources (e.g. the lexers and parsers produced by Flex
        and Bison) are not included because they are long, unwieldy, and serve
        no expository purpose beyond their source counterparts.
\end{itemize}

The script and \LaTeX\ template used to create this document can be found online
at \url{https://github.com/oliverdixon/OptiFOL-Software/tree/master/Typeset}.
Doxygen HTML documentation of the sources can be found at
\url{https://www-users.york.ac.uk/~od641/l6-project/doxygen}.
