# Optifol Software

*Optifol* ("optimised first-order logic") was the software artefact of my penultimate year (Level 6) degree project
at the University of York. The documentation, including the full report, can be found at
https://github.com/oliverdixon/OptiFOL-Documentation.

Overall, the project scored 81/100 points.
